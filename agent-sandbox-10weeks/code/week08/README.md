# Tuần 08 — Code mẫu

## `tool_runner.py`
Wrapper chạy tool an toàn (whitelist + denylist).

```bash
python tool_runner.py --cmd 'ls -la'
```

**An toàn:** script chỉ mô phỏng bằng dữ liệu, không chạy tool/lệnh thật, không đụng hệ thống.
