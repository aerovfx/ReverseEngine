# Bài tập Tuần 04 — Snapshot & restore

## Cơ bản
Giải thích snapshot bộ nhớ khác snapshot ổ đĩa.

## Nâng cao
Mô tả 4 bước của restore path.

## Thử thách
Ước lượng vì sao snapshot nhỏ hơn nhiều so với RAM tổng.

## Nộp bài và rubric
Nộp báo cáo (sơ đồ/log) + script nếu có. Rubric 100 điểm: đúng chức năng 35; an toàn & pháp lý 25; chất lượng tài liệu/code 20; phân tích và bằng chứng chạy 20.

> **Pháp lý:** chỉ phân tích/dựng sandbox trên hạ tầng của bạn hoặc mã nguồn mở. Không tấn công/thoát sandbox của người khác.
