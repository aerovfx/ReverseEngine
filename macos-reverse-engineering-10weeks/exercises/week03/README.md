# Bài tập Tuần 03 — macOS Internals

## Cơ bản
Giải thích vai trò của `isa`, `objc_msgSend`, method list trong Objective-C.

## Nâng cao
Dùng `class-dump` trên app của bạn và liệt kê các method không có trong source (nếu có).

## Thử thách
Viết mô phỏng `objc_msgSend` bằng Python và giải thích luồng dispatch động.

## Nộp bài và rubric
Nộp bảng so sánh runtime Objective-C vs Swift + output class-dump/swift-demangle. Rubric 100 điểm.

> **Pháp lý:** chỉ chạy class-dump trên app của chính bạn / được cấp phép.
