# Bài tập Tuần 07 — Network & Persistence

## Cơ bản
Liệt kê các vị trí persistence trên macOS.

## Nâng cao
Tạo LaunchAgent cho app của bạn và kiểm tra qua `launchctl`.

## Thử thách
Viết script quét `~/Library/LaunchAgents` và tóm tắt mỗi plist.

## Nộp bài và rubric
Nộp báo cáo network/persistence + output Wireshark/launchctl. Rubric 100 điểm.

> **Pháp lý:** chỉ phân tích mạng/persistence của app của chính bạn / được cấp phép.
