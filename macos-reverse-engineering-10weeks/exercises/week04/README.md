# Bài tập Tuần 04 — Static Analysis

## Cơ bản
Liệt kê các bước static analysis và công cụ dùng cho từng bước.

## Nâng cao
Dùng Ghidra decompile `main` của app bạn viết và giải thích luồng.

## Thử thách
Viết báo cáo static hoàn chỉnh cho một app mã nguồn mở, kèm bằng chứng output.

## Nộp bài và rubric
Nộp báo cáo static + output script/codesign. Rubric 100 điểm.

> **Pháp lý:** chỉ phân tích static app của chính bạn / được cấp phép / mã nguồn mở.
