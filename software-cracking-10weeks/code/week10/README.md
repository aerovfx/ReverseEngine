# Tuần 10 — Code mẫu

## `serial_check.py`
Mô phỏng thuật toán kiểm tra serial + keygen hợp pháp.

```bash
python serial_check.py --keygen Alice
```

**An toàn:** script chỉ mô phỏng/đọc dữ liệu, không thực thi binary, không sửa file gốc.
