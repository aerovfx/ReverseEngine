# Tuần 02 — Code mẫu

## `die_sim.py`
Đọc magic bytes và đoán định dạng/compiler như Detect It Easy.

```bash
python die_sim.py <file>
```

**An toàn:** script chỉ mô phỏng/đọc dữ liệu, không thực thi binary, không sửa file gốc.
