# Bài tập Tuần 08 — RE Malware macOS mẫu 1

## Cơ bản
Liệt kê các bước phân tích malware macOS và công cụ dùng.

## Nâng cao
Phân tích static mẫu XCSSET được cấp phép trong VM, ghi lại IOC.

## Thử thách
Viết báo cáo IOC hoàn chỉnh gồm static + dynamic + network + persistence.

## Nộp bài và rubric
Nộp báo cáo RE mẫu 1 + bằng chứng (log/ảnh/output). Rubric 100 điểm.

> **Pháp lý:** chỉ phân tích mẫu được cấp phép trong VM cô lập; không phát tán, không chạy trên máy chính.
